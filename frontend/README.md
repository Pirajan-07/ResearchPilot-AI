# ResearchPilot AI — Frontend

This is the Next.js 15 frontend for the **ResearchPilot AI** project.

**Primary documentation:** See the root [`README.md`](../README.md) for full project setup instructions, architecture overview, and API reference.

## Quick Start

```bash
# From this directory:
npm install
npm run dev
```

Frontend runs at **http://localhost:3000**. The FastAPI backend must be running at **http://localhost:8000**.
